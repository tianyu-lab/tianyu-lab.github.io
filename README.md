# Tianyu AI Framework

Tianyu AI Framework is an experimental platform for embodied AI and precision robotic control.

## Status

The project is currently undergoing internal algorithmic verification and optimization.

## Ethics & Prohibited Applications

This framework MUST ONLY be applied to applications that directly benefit human health, medical life-saving, and human well-being (e.g., non-invasive capsule surgical robots, anatomical simulation, precision medical cutting).

Weapons, military applications, and harmful commercial exploitation are STRICTLY PROHIBITED.
